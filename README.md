## Introduction

This dashboard was developed in a previous role to solve complex business problems related to depot-level stock monitoring and performance tracking.  
The key challenge was working with unclean and massive datasets while ensuring the end product was insightful, interactive, and visually appealing.

**Note:** In respect of organizational confidentiality, all values have been replaced with dummy data while keeping the structure, logic, and features intact.

---

## Objective 🎯

- **Goal**: Enable business users to monitor stock performance, depot-level metrics, and key insights at a glance.
- **Role**: As a BI Analyst, I led the development of this dashboard using Power BI.
- **Scope**:
  - Addressed data inconsistencies and transformation needs.
  - Built visuals to track real-time depot stock status.
  - Ensured responsiveness and a mobile-friendly layout.
  - Highlighted how data impacts business decisions.

---

## Key Features

- **Stock Overview**: Real-time summary of depot stock levels.
- **Interactive Filters**: Select by depot, product, or region.
- **Performance Indicators**: Metrics like stock status, alerts, and variations.
- **Mobile Responsive View**: Designed for seamless viewing on mobile devices.
